# Furnace assembly photographs

Photographs of the assembled, operating furnace contributed by R. Guymon in
[PR #3](https://github.com/vertical-cloud-lab/custom-induction-furnace/pull/3)
(July 2026). Rendered into manuscript figures by
`paper/build_photo_figures.py` (`make figures` in `paper/`).

| File | Content |
| --- | --- |
| `furnace-assembled.png` | Fully assembled, functioning furnace; the coil / CEIA Power Cube on the support stand, quartz-tube chamber glowing at temperature, argon cylinder behind, turbo pumping station at right. |
| `relief-valve.png` | Overpressure relief valve at the bottom of the vacuum chamber stack (0.5 psi cracking pressure). |
| `mfc-argon.png` | Sierra Smart-Trak digital mass flow controller connecting the argon tank to the vent valve. |
| `roughing-pump-isolation.png` | Pumping station with the roughing pump placed on a separate support, not connected to the vacuum-chamber attachment tubes, to decrease vibration transmitted to the chamber (chamber shown disassembled). |
