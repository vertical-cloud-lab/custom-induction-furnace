# Furnace assembly photographs

Photographs of the assembled, operating furnace contributed by R. Guymon in
[PR #3](https://github.com/vertical-cloud-lab/custom-induction-furnace/pull/3)
(July 2026). Rendered into manuscript figures by
`paper/build_photo_figures.py` (`make figures` in `paper/`).

| File | Content |
| --- | --- |
| `assembled-furnace-callouts.pdf` | Source slide (R. Guymon): the assembled, operating furnace with part call-outs (pyrometer, vent valve, quartz vacuum chamber, induction coil, sample stack, Power Cube generator, vacuum gauge, turbopump, roughing pump). |
| `furnace-assembled-callouts.png` | Crop of the slide above; the manuscript's assembled-system figure. |
| `furnace-assembled.png` | Unannotated original of the same view: the coil / CEIA Power Cube on the support stand, quartz-tube chamber glowing at temperature, argon cylinder behind, turbo pumping station at right. |
| `relief-valve.png` | Overpressure relief valve at the bottom of the vacuum chamber stack (0.5 psi cracking pressure). |
| `mfc-argon.png` | Sierra Smart-Trak digital mass flow controller connecting the argon tank to the vent valve. |
| `roughing-pump-isolation.png` | Top-down view of the assembled turbo pumping station with the roughing pump placed on a separate support, coupled only through a flexible hose, so its vibration is not transmitted into the vacuum chamber. |
